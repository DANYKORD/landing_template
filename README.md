# 🚀 Universal Landing Page Template

Сучасний, швидкий та дуже зручний шаблон для лендінг-сторінок (односторінкових сайтів). Головна перевага цього шаблону — **повна відсутність необхідності знати програмування для його налаштування**.

Усі тексти, ціни, зображення, відгуки та навіть налаштування інтеграцій (Нова Пошта, Google Sheets) змінюються в одному зручному файлі — `config.js`.

## ✨ Основні переваги

- **Конфігурація без коду**: Змініть файл `config.js`, і весь сайт оновиться автоматично.
- **Вбудована інтеграція з Новою Поштою**: Розумний пошук міст та відділень з автоматичним підтягуванням списків через API Нової Пошти (без вікон і зайвих віджетів).
- **Відправка замовлень у Google Sheets**: Усі заявки автоматично записуються в Google Таблицю (звідки легко налаштувати пересилку в Telegram).
- **Сучасний дизайн**: Оптимізований для мобільних пристроїв, швидкі анімації, спливаючі модальні вікна.
- **Таймер акції**: Вбудований лічильник зворотного відліку для стимулювання продажів.

## 🛠 Як налаштувати під себе?

1. Скопіюйте файл `public/config.example.js` і перейменуйте його на `public/config.js`.
2. Відкрийте `public/config.js` у будь-якому текстовому редакторі.
3. Вкажіть свої дані:
   - Назву компанії та товару, ціну, валюту.
   - Замініть зображення в папці `public/assets/` та вкажіть нові назви файлів у конфігу.
   - Вставте свої API ключі для інтеграції з Новою Поштою та посилання на веб-додаток Google Script.
4. Збережіть файл! Ваш лендінг готовий до роботи.

## 🚀 Запуск та розробка

Проект побудований на **React** + **Vite** + **Tailwind CSS**.

### Встановлення залежностей:
```bash
npm install
```

### Запуск локального сервера (для перевірки):
```bash
npm run dev
```

### Збірка проекту (для завантаження на хостинг):
```bash
npm run build
```
Після виконання команди `npm run build`, ви отримаєте готову до розгортання папку `dist/`. Ви можете просто завантажити її вміст на будь-який хостинг!

## 🔐 Безпека

Зверніть увагу, що файл `public/config.js` з реальними ключами додано до `.gitignore`, тому він не відстежується Git і не потрапляє у відкритий доступ. На GitHub зберігається лише безпечний `public/config.example.js`.
